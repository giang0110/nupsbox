# NupsBox

Modern bilingual conversion website and lightweight CRM for **NupsBox – Cho thuê kho mini làm địa điểm kinh doanh tại TP.HCM**.

- Production domain: `https://nupsbox.vn`
- Stack: Next.js 16.3.3, TypeScript, Tailwind CSS 4.3, Supabase, Vercel
- Default locale: Vietnamese (`/`)
- English locale: `/en`

See `docs/superpowers/specs/` and `docs/superpowers/plans/` for the approved architecture and Phase 1 plan.
