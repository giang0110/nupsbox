# NupsBox

Bilingual **commercial information website** and lightweight CRM for NupsBox in Ho Chi Minh City.

The public experience is information-first: services, facilities, real imagery, articles, company information and contact channels. Legacy mini-storage, pricing and booking routes remain available as supporting detail pages, while the primary navigation no longer centers the booking funnel.

- Current production origin: `https://nupsbox.vercel.app`
- Intended custom domain: `https://nupsbox.vn` (switch `NEXT_PUBLIC_SITE_URL` only when DNS/domain rollout is complete)
- Stack: Next.js 16.3.3, TypeScript, Tailwind CSS 4.3, Supabase, Vercel
- Default locale: Vietnamese (`/`)
- English locale: `/en`
- Admin foundation: CMS, CRM leads, media, FAQ/blog, catalog, pricing, locations, roles, analytics and audit

See `docs/superpowers/specs/2026-09-29-p350-commercial-information-web.md` for the current public positioning and `docs/superpowers/specs/` for prior architecture decisions.
